# 47県全面再制作・遊びの重複監査

2026-09-05のユーザー指示により、旧エンジンの名前だけの47モードを完成品として扱わない。
この表は**設計**。実装済み・実機検証済みと混同しない。

共通化するのは入力座標、描画、音量、セーブ、時間管理まで。キャッチ・照準・移動などの基本動詞が共通でも、目的、操作の結果、判断、ステージ展開が同じなら別ゲームとして数えない。
各県のモチーフは既存の県データに合わせる。追加の地域事実をプロフィールへ書く際は別途公式出典を確認する。

## 品質ゲート（各ゲームに必須）

1. 説明中は時間を減らさず、図と動作見本を出す。
2. 最低目標達成で自動打ち切りせず、約45秒または一周の展開を最後まで遊ぶ。
3. 初回操作、成功、失敗、再挑戦、クリアのすべてで結果が見える。
4. タッチ・ペン・マウスの押す／動かす／離す／キャンセルを確認する。
5. 正しい操作でクリアでき、誤操作で回復不能にならない。
6. 画面サイズを変えても指で操作する場所と説明が重ならない。
7. 再プレイ時に判断・操作が変化する。ランダムな飾りだけは不可。
8. 成功時には喜ぶシルエットと鳴き声、何点取れたか、再プレイボタン。
