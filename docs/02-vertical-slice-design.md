# 3県縦切りプロトタイプ設計

## 採用県

- 青森県: りんごキャッチ。左右移動と落下物の予測。
- 香川県: うどんのびのび。長押し時間の調整。
- 沖縄県: ちんすこうサーフィン。自由ドラッグと回避。

3県は地域・文字数・操作が異なり、縦切りでゲーム全体の幅を検証しやすい。

## 1セットの流れ

`ホーム → 全国地図で場所を発見 → ひらがな練習 → 漢字練習 → ご当地ゲーム → 場所クイズ` を3県繰り返し、`地図おさらい → ひらがな → 漢字 → 仲間獲得 → 図鑑/もう1セット` へ進む。場所クイズでは県名なしの正確な全国地図を直接タップし、回答後に正しい県形を表示する。おさらいは各県ごとに、全国地図で対象県だけを赤く光らせて「ここはどこ？」と問い、答えを確認してから書き取りへ進む。

## 横画面1画面ルール

- すべての画面を `100dvh` 内に収め、ページスクロールを発生させない。
- 上部はロゴ・短い問題文・音量だけに絞る。進行度バーは置かず、中央の地図・手書き面・ゲーム面を最大化する。
- 1024×600を基準に、1366×768、1920×1080、スマートフォン横667×375まで確認する。
- 高さが少ない端末では余白、見出し、補助文を縮め、地図・手書き面・ゲーム面を優先する。
- タッチ対象は原則44px以上。マウス、指、ペンで同じ操作を可能にする。

## 日本地図

- ユーザー指定のFrame illust「日本地図のイラスト（県境入り）」を画面の基準素材として使用する。
- 元PNGの県境で囲まれた領域から、47都道府県の選択用透過画像を機械生成する。
- 元PNGに含まれる沖縄県の別枠、島、県境、海岸線を移動・描き直しせず、1600×1000の共通キャンバスへ配置する。
- 地理形状と演出を分離し、選択時は塗り、外周光、カメラ移動だけを変える。
- 初期表示は全土、出題時は全国で位置を示したあと対象県へ滑らかに寄る。戻す操作を常設する。

## データ構造

`PREFECTURES` にコード、漢字、読み、地域、ゲーム種別、キャラクター、色を持たせる。画面遷移は `state.view`、現在県は `state.round[state.roundIndex]` から決める。セーブは `localStorage` に獲得県コードと音量設定だけを保存する。

## 手書き

- Canvasの座標を表示サイズから内部座標へ変換し、端末解像度に左右されない線を描く。
- 一画戻す、全部消す、薄いなぞり表示を用意する。
- 初期版は認識判定を行わず、少なくとも1画書いたら自分で見比べて進める。

## アニメーションと音

- ボタンは押し込み、地図は光とズーム、描線は小さな粒子、成功時は短いバーストで応答する。
- `prefers-reduced-motion` では大きな移動を止める。
- 効果音はWeb Audioで短く合成し、外部音源を使わない。音量切替を保存する。

## 完了条件

- 3県を重複なく1セット遊べる。
- 地図、2種類の手書き、ゲーム、ゲーム後の場所クイズ、おさらい、獲得、図鑑、図鑑から再プレイが動く。
- 横画面でスクロールせず、地図が主役として十分な面積を取る。
- 再読み込み後も獲得状況が残る。
