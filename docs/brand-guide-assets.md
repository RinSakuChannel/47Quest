# 47Quest brand and Japan guide

The UI brand is a code-native wordmark, so it stays sharp, readable and consistent at every viewport size. The old generated raster logo and guide are no longer shipped. Learning maps remain unchanged.

- Header and title: HTML/CSS wordmark using `47`, a teal `Q`, and a navy `uest`.
- `assets/images/japan-guide-simple.svg`: 512 × 512 viewBox. 2026-09-12に、小表示でも表情が読める丸い体、大きな顔、短い四肢、北海道の耳と沖縄の3点だけに整理した。これは装飾キャラクターであり、学習用地図には使用しない。

The mascot SVG is drawn from simple vector primitives maintained in this repository. It is intentionally not a geographic teaching map.
