## 今回の合格条件

- 47県すべてに固有のタイトル、操作、説明、再挑戦時の変化がある。
- 10〜30秒で終了し、押す・動かす・離すなどの入力へ即時反応する。
- 無操作だけではクリアせず、画面に示した操作でクリアできる。
- 成功、失敗、惜しい状態を、盤面・音・短い文言で区別する。
- 結果画面に、その県で次回変化する内容を表示する。
- PC、タブレット、スマホ縦横で盤面を画面内に収める。

## 今回修正した再現不具合

- 愛媛：ランダムな波門位置で負の高さが発生し、Canvas描画が停止する場合があった。
- 山口・愛媛：初期状態と正解が偶然一致すると、無操作で通過できた。
- 福島：初期位置へ鈴が落ちるだけで得点になる場合があった。
- 福岡：二段ジャンプの成功猶予が幼児向けとして狭く、失敗反応も不足していた。
- 青森：金りんごで目標を超えると `9 / 8` のように表示された。
- 香川：1回成功後の待ち時間が負数で残り、2杯目以降を操作できなかった。
- 全44地域ゲーム：実際には変速しないゲームにも「少し速くなるよ」と表示していた。
