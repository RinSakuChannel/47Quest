# ご当地キャラ再制作

## 必須条件

- 1体1枚で生成する。集合絵を分割しない。
- 本体の輪郭が主モチーフ。既存の動物に名産品を持たせるだけにしない。
- 県を知らない子でも「りんご」「落花生」「うどん」などを絵から答えられる。
- 64pxで読める輪郭、太さが安定した線、少ない色面。写真風の質感と細かな装飾を増やさない。
- 完全オリジナルの生き物。既存作品の顔、配色、装備を参照しない。
- 全身と透明背景。耳・しっぽ・つるを切らず、周囲に余白を残す。
- 採用前に主モチーフ、背景透明、隣の断片、解像度、容量を確認する。
- ゲーム上の性格・能力と、地域の事実を表示上でも分ける。
