# 47Quest 検証・公開記録

更新日: 2026-09-12

## 今回の修正範囲

- 47ミニゲームの定義を個別に照合し、47固有タイトル、46種類の操作表現、47固有のランダム変化を登録した。
- 44本のCanvasゲームに、操作表示、押下波紋、失敗フラッシュ、成功パーティクル、県ごとに変わる背景を追加した。
- 青森・千葉・香川の専用DOMゲームを含め、全ゲームを最大20秒に統一し、目標達成時は即座に終了するようにした。
- 全ゲームの開始画面を「操作」「やること」「スタート」の1本に整理し、難易度選択、星条件の先出し、重複説明を撤去した。練習は任意の副導線として残した。
- 県ごとの背景を雪・海・森・祭り・工芸など12系統へ描き分け、共通の丸模様背景を撤去した。
- 一時採用した量産型SVGキャストを撤去し、「奇妙だがまた見たくなる」個別制作キャラクター47体へ復帰した。採用内訳はv3の37体と個別再制作済みv4の10体。
- キャラクター画像を再び公開ビルドへ含め、ゲーム説明、獲得画面、図鑑、詳細、タイトル、ミニゲーム内の参照切れを解消した。
- 獲得画面と図鑑のキャラクター表示領域、スマホ小画面の見切れ、図鑑カード装飾による疑似スクロール、ゲーム画面の重なり順を修正した。
- タイトルは毎回47体から重複なしで6体を選び、未獲得でも実画像を隠さず見せる。左上は文字ロゴだけにし、主操作1つ＋短い3導線へ整理した。
- 音と演出を1つの設定ボタンへ統合し、保存済みの音ON/OFFを次回起動時に復元する。保存不可時は画面上へ明示する。
- 大分の旧「温泉たまご」ゲーム名・説明をデータから除去し、現キャラクターを使う「湯の花 三色めぐり」へ統一した。

## 未完・未検証

以下は今回「完成」「検証済み」とは扱わない。

- 実機のタッチペン、複数機種のiOS/Androidタブレット、Safariでの操作確認。
- 5歳児・小学4年生・大人による実プレイ観察。ルール理解、難易度、もう一度遊びたいかの評価。
- 44本のCanvasゲームすべてについて、人が最後まで操作してクリアできることの個別プレイ検証。自動試験済みなのは生成、描画、入力反応、有限座標、キャンセル処理であり、全クリア保証ではない。
- キャラクターの口・目・手足を別レイヤーで動かす部位アニメーションは、最新方針により実装対象外。現版は既存画像を保った短い全身リアクションのみ。
