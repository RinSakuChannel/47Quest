# 都道府県プロフィール情報の出典方針

更新日: 2026-09-05

図鑑プロフィールの「名産・名物」「こんな場所」は、子ども向けに短く要約している。制作時の基礎資料には次の公的情報を使用した。

- 農林水産省「うちの郷土料理～次世代に伝えたい大切な味～」
  - https://www.maff.go.jp/j/keikaku/syokubunka/k_ryouri/index.html
  - 47都道府県の郷土料理、食文化、地域背景を確認するために使用。
- 日本政府観光局（JNTO）「Destinations」
  - https://www.japan.travel/en/destinations/
  - 各地域の自然、文化、代表的な観光要素を確認するために使用。

## 表示上の区別

- 「名産・名物」「こんな場所」は学習用の地域情報。
- 「げんき」「すばやさ」「ひらめき」「レア度」「とくいわざ」はゲーム内キャラクターの架空データであり、地域の統計値ではない。
- キャラクター画像は県コード順に固定し、主モチーフ、名前、プロフィール、ミニゲームの題材が食い違わないよう管理する。
