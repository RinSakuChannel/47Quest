# ミニゲーム改善（2026-09-07）

既存47県企画を維持し、以下の3県の操作を変更。

|県|遊び|変化と再挑戦|操作|
|---|---|---|---|
|岩手|3人のおかわり注文へ5杯届ける|食べ終わる時間が毎回変化。後半は待ち時間が短い|空のおわんをタップ|
|愛知|しゃちほこの水玉で屋根の火を3つ消す|火が揺れ、後半は動きが大きくなる。飛行時間を見て狙う|火へ照準を合わせて離す|
|京都|扇の風で花びらを3回輪へ通す|輪の位置が毎回変化。風を当てる左右位置で軌道が変化|花びらの下をタップ|

ご当地モチーフは既存のものを継続。3作品とも最大20秒、目標達成時は待たずに終了する。
44県共通の一連の達成を3点に変更し、一度達成すれば星1つ。
成功時の盤面を覆う表示を撤去、既存のバナーと達成地点の粒子で伝える。
成功後は短い手応えだけを返し、次の課題へ進む。共通の本番では目標到達後480msで結果へ移る。

自動操作はクリア可能性・無操作で勝てないこと・キャンセルを検証。
楽しさそのものは子どものプレイ評価が必要であり、自動テストだけで判定しない。
