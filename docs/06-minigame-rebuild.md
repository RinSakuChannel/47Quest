# ミニゲーム再設計（2026-09-05）

## 公式情報から参考にする点

- [メイド イン ワリオ](https://www.nintendo.com/us/store/products/warioware-move-it-switch/): 振る・突く・踊るなど操作そのものに違いがある。短さだけをまねない。
- [ヨッシークラフトワールド](https://www.nintendo.com/sg/switch/aea2/index.html): 裏側からの探索、収集、やさしく遊べるモード。達成後にも試したいことを残す。
- [ピクミン4](https://pikmin4.nintendo.com/): 巻き戻しによるやり直し。失敗の損失を小さくする。

以下は上記を踏まえた本作独自の設計判断であり、各作品の効果を実証したものではない。既存の絵・音・ルールの具体的コピーはしない。

## 最初に作り直す3本

|県|遊び|45秒の展開|繰り返す理由|やさしさ|
|--|--|--|--|--|
|青森|左右にかごを動かす果樹園キャッチ|一個ずつ→風で揺れる→金りんごの収穫祭|軌道、金りんご、連続キャッチ|大きなかご、落としても得点没収なし|
|千葉|ベルト上の落花生と葉を別の箱へドラッグ|ゆっくり→同時に二個→金の落花生|流れる順序と仕分け判断|文字だけでなく箱にも同じ絵、誤投入は元へ戻る|
|香川|麺を引き上げ、注文の長さで離す|短い注文→長い注文→大盛り|伸びる麺の手触りと毎回違う注文|注文の帯を常時表示、失敗はすぐ引き直せる|

最低目標を達成しても45秒まで遊べる。星2・3の目標を先に見せる。時間切れ未達成なら練習を継続し、達成時にクリアする。説明画面は開始を押すまで消さない。非表示タブでは時間を進めない。
