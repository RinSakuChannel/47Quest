# 47都道府県ミニゲーム企画

実装前の全県企画。縦切り版は、操作の異なる青森（左右移動）、香川（長押し）、沖縄（ドラッグ）の3県を採用する。ご当地モチーフは本実装時に自治体・官公庁・観光公式情報で再確認する。

## v3実装監査（2026-08-14）

旧実装は企画表が47種類でも、実際のコードでは10種類の共通ゲームへ集約され、県名と絵文字を替えただけの県が多かった。v3では全47県に別々の `mode` を割り当て、命令、勝利条件、対象の動き、入力の扱いのいずれかを必ず変えた。制限時間は6〜10秒、開始時は0.85秒の一声命令を出し、成功時は即座に光・拡大・効果音を返す。

`course / catch / reaction / flick / reveal / connect / balance / maze / pullshot / mash / flip / sort / ringbuild / steer / stack / memory / feather / scrub / bounce / road / flap / rhythm / lane / circle / slalom / match / multitimer / drawroute / throw / chaincatch / dodge / outline / care / redirect / size / sequence / hold / wave / timing / jump / catchsort / slide / safe / pop / peel / pull / freedodge`

上記47モードは `src/microgames-v3.js` の47件の県コードと1対1で対応する。企画だけが別物で実装は同じ、という状態へ戻さないため、47件・47コード・47モードの重複検査に加え、全モードを同時起動して空画面、実行時例外、縦方向のUI切れを検査する。共有しているのはタイマー、成功演出、ポインター処理などの低水準部品だけで、県別の操作・判定・目標はモード側で分岐する。

## 重複チェック

- 3県縦切り版は「横移動」「長押し」「自由ドラッグ」で操作が重ならない。
- 47県版も、キャッチ、タイミング、探索、物理、経路、リズム、仕分けを連続させない前提で実装順を組む。
- 固定解を暗記するゲームは採用せず、位置・速度・順序・軌道のいずれかを毎回変える。
