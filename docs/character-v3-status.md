# リアルで奇妙なご当地生物への変更

参考: https://www.feel-kobe.jp/event/35401/
参照したのは現実の素材と奇妙な生態を組み合わせる方向性。既存のキャラクター・説明・台詞を複製しない。

## 実装済み（ローカル、未公開）
- `src/character-personalities.js`: 47体それぞれの架空の生態説明、専用の2軸ステータス、異なる日本語台詞、読み上げ速度・高さ。
- 特産物と地理の既存の事実欄を残し、架空の生態と区別。
- 47本の日本語台詞をWindows合成音声（Ichiro/Ayumi/Sayaka）でWAV生成。声と速さは性格ごとに設定。声優の演技音源ではなく合成音声。聴感は未検証。音声ファイル再生非対応時のみ端末読み上げを使用。
- 音量は効果音スライダーに追従。音量変更・ミュート・画面切り替えで進行中の発話を停止。
- おさらい1県完了につき1コイン。3県で3枚。1枚につき47県から等確率に1体抽選し、重複あり。抽選結果は地図・県名・読み・特産物・ステータスと一緒に表示。

## 画像
新方向の北海道・青森・岩手を `assets/characters/v3/01.webp`～`03.webp` に保存し、実行時参照を変更。雪の口、耳りんご、三つ口わんこそばとして器官を素材に統合した。
山形の三つ目さくらんぼと、既存の新方向素材も `assets/characters/v3/05.webp`～`06.webp` 等へ反映。
神奈川は「シラスの群体と巨大な一眼」の新基準で `assets/characters/v3/14.webp` に反映。異常な器官の数は固定せず、一眼・多眼・口・耳・指・器官なしの異常形などを県ごとに変える。
その他は生成・透過と縁の検査中。画像を生成しただけでは完成に数えない。現在、品質確認済みの新方向差し替えは37体分（テスト計測）で、残りは既存の軽量素材を使用。
01・03・05～09は原寸WebPで保存したが、元PNGから赤・黄の縁が残り採用保留。04は透過なし。04と06の画像生成による修正も透過なしだった。残り38体の生成は、透過不具合の解決前に枠を浪費しないよう一時停止。
最終検査: 47本のWAVが存在し、PCMサンプルが非無音であること、音量値と停止処理、47種の台詞、コイン重複付与防止・残高不足・重複抽選をテスト。総ビルド15.82MiB（16MiB以内）。
旧画像は保存し、品質確認できた画像だけ差し替える。
組み込み画像生成を使用。原寸を維持してWebP形式に変換し、切り抜きや拡大は行わない。
