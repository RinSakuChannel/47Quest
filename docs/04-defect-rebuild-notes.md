# 欠陥修正と再構成メモ（2026-08-14）

## 修正した問題

- 出題対象が青森・香川・沖縄の3県に固定されていた問題を解消し、47県から同一セット内重複なしで3県を抽選する。
- 直前セットの3県は、次セットで可能な限り避ける。
- 空欄や極端に小さい線だけを入力不足として止め、通常の手書きは筆画数で誤って足止めしない。字形の正誤は次の比較画面で確認する。
- 一部のタッチ・ペン環境で `pointerup` が届かず進行ボタンが有効にならない問題を解消し、描画中・入力終了・ポインター捕捉解除の各時点で状態を更新する。
- 進行ボタンをキャンバス右下へ移し、横画面やブラウザ拡大時にも見失いにくくする。
- 練習を正解判定として扱わない。おさらいでは自筆画像と正解を並べて比較する。
- おさらいを県ごとに「①ひらがな」「②漢字」の2段階へ分離する。
- 両方を見本なしで書けた県だけを獲得対象にする。ヒント利用時は練習扱いにする。
- 県名と絵文字だけを替えた旧10種類の共通ゲームを廃止し、47県を47個の固有モードへ分離した。短い一声命令の後、6〜10秒で完結し、県ごとに入力、勝利条件、動き、判定、ランダム要素のいずれかが変わる。
- 似ていた操作も再分離した。例として、埼玉は焼けた瞬間だけ返す複数タイマー、千葉は見本との即時仕分け、東京は番号順の土手閉じ、熊本は一瞬見えた安全路の順番記憶、宮崎は葉を実際にめくるドラッグ操作とした。
- `tests/microgames-smoke.html` で47件・47モード・空画面なし・縦方向のUI切れなし・実行時エラーなしを一括検査する。
- ゲームで詰まらないよう、再挑戦に加えて「ゲームはあとで」を用意した。
- 正確な全国地図の座標から47県分のハイライトを生成し、選択県を中央付近へ拡大できるようにした。
- 図鑑を47県・1ページ6県・全8ページへ拡張した。
- 各ミニゲーム直後に場所クイズを追加した。番号付き候補は地図を隠すため廃止し、全国地図を直接タップする。誤答時は直前のクリック位置だけに小さな印と近隣県ヒントを出し、回答後は正確な県形オーバーレイを表示してから次県へ進む。
- 順番当てゲームは自動開始を廃止した。「順番を見る」を押してから見本を再生し、「もう一度見る」で同じ順番を再確認できる。見本再生中は制限時間を止める。
- おさらいの最初に、対象県だけを赤く光らせた大きな全国地図を表示し、「赤く光っている県はどこ？」と声に出して答える段階を追加した。答えを表示した後に、ひらがな・漢字の書き取りへ進む。
- おさらいの問題文とヒントは左側パネルではなく画面上部へ移動し、地図と手書き欄を横画面の中央いっぱいに広げた。
- 全画面の進行度バーを撤去した。上部には現在の問題だけを短く表示する。
- 日本地図が出る全画面で、Frame illustの指定素材から生成した共通地図・47県ハイライト・注目座標を使用する。表示画像とクリック判定が別座標にならないよう、すべて同じ1600×1000キャンバスから生成する。
- ミニゲームは左説明パネルを撤去して遊び場を全面化し、操作説明を上部の一声命令へ短縮した。制限時間は原則8〜12秒、目標数は2〜5回に短縮した。
- 表示用地図と異なる旧座標変換を廃止し、1600×1000の表示用オーバーレイから全47県の正解点を再計算した。47点すべてが該当県の不透明ピクセル上にあることを一括検証済み。
- 場所クイズの表示枠を地図画像と同じ8:5へ修正し、レターボックス分だけ正解リングが南へずれていた問題を解消した。
- 日本地図だけを対象に、2本指ピンチ、`Ctrl`＋ホイール、拡大後のドラッグ移動を追加した。拡大後のクリックは逆変換してから県形状で判定する。
- 下部操作UIに画面端・セーフエリアからの余白を確保し、手書き画面のお手本は文字数に応じた1行固定の文字サイズへ変更した。

## 判定の方針

初期版の仕様どおり、高精度文字認識は実装しない。現在の書字チェックは「文字らしい量を書いたか」を確認する入力ゲートであり、字形の正誤判定ではない。正解は自動付与せず、正答との比較後に本人が選ぶ。将来の文字認識追加に備え、キャンバスの筆跡は画単位の配列として保持する。
