# 日本地図データ・加工記録

## 採用データ

- データ名: 国土数値情報「行政区域データ（N03）」2024年版
- 提供元: 国土交通省
- データ基準日: 2024年1月1日
- 取得元: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2024.html
- 使用許諾: オープンデータ（CC BY 4.0）。取得元に記載された注意事項にも従う。
- 加工者: 47Quest

アプリ画面とリポジトリ内のドキュメントに出典を表示する。公開前には、取得元に記載された測量法上の注意事項を含め、公開形態に必要な手続きがないかを再確認する。

## 加工内容

- 元GeoJSONの行政区域座標をWebメルカトルへ投影する。
- 全都道府県を同じ縮尺・同じ投影・同じキャンバスへ描画する。
- 都道府県の境界座標、海岸線、島しょ部を手描き・移動・変形しない。
- 画面用PNGは公式データから生成したSVGをラスタライズしたものを使う。
- 各県の赤い選択表示は、同じ行政区域座標から生成した透明PNGを重ねる。
- 県の注目座標は、各県で最大の地物の内部点から算出する。
- 本州・北海道・四国・九州を大きく表示し、沖縄・南西諸島は同一縮尺のまま左下へ分けて表示する。
- 左下の沖縄表示には白い囲みを置かず、海の背景へ自然につなげる。
- 極小の島でも押せるよう、地形を変更せず入力判定レイヤーだけを広げる。

- 表示用配置の生成処理: `scripts/build-display-maps.ps1`

表示用地図と選択画像は同じ8:5の座標空間を使用する。タップ座標も同じ変換式で再生成し、表示と判定を一致させる。

## 公開物に含めないもの

元GeoJSON、地域別ZIP、巨大な中間SVGは再生成用の開発データであり、Web配信用ビルドとGitHub公開対象から除外する。配信物には軽量な表示用PNG、47県の透明PNG、出典表示だけを含める。
