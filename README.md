# 47Quest

日本全国を冒険しながら、47都道府県の場所・ひらがな・漢字を覚える横画面Webゲームです。

公開版: https://rinsakuchannel.github.io/47Quest/

## 起動方法

Node.js 18以上が入っているPCで、このフォルダをPowerShellまたはターミナルで開き、次を実行します。

```powershell
node server.mjs
```

そのままターミナルを閉じずに、ブラウザで次を開いてください。

```text
http://127.0.0.1:4173
```

終了するときは、サーバーを実行したターミナルで `Ctrl+C` を押します。追加パッケージのインストールは不要です。

## 現在の実装

- 47都道府県から重複なしで3県を抽選
- 国土交通省「国土数値情報（行政区域データ・2024年）」を基にした全国地図と、同じ行政区域座標から生成した47県別ハイライト
- 選択県を中央付近へ大きく表示する地図ズーム
- ひらがな練習と漢字練習を別画面で実施
- 空欄や極端に小さい線を拒否し、通常の手書きは止めずに比較画面へ進行
- おさらいは大きな全国地図の「赤く光っている県はどこ？」から始め、答えを確認してから「ひらがな→答え合わせ→漢字→答え合わせ」を県ごとに実施
- 問題文は上部へ集約し、地図・手書き欄の面積を減らす進行度バーは表示しない
- 一声の指示で始まり8〜12秒で決着する、10種類の短いご当地ゲーム
- 各ミニゲーム直後に、全国地図を直接タップして県の位置を当てる場所クイズ
- 47県対応の8ページ図鑑とブラウザ内セーブ

## 判定について

現在はAI文字認識を使っていません。書いた文字を自動で「正解」と断定せず、最低限の書字量を確認した後に正しい文字との比較画面を表示します。見本を見た場合は「見本なしで正解」として登録できません。

地図データの出典・加工内容は [docs/03-map-data-record.md](docs/03-map-data-record.md) を参照してください。
